# 桌面端使用指南

## 窗口本身

没有系统标题栏。顶栏就是窗口边缘：

- **拖动窗口**：按住顶栏任意空白处，或左上角的品牌区。
- **三枚控制钮**在右上角，是 UI 自己的玻璃圆钮（最小化 / 最大化·还原 / 关闭），
  和顶栏同一材质、同一悬停反馈；最大化时自动去掉圆角，还原后再长回来。
- **改窗口大小**：鼠标贴到任意边缘（外圈 6px 是透明热区），右下角有可见的抓取纹理。
- 关闭按钮就是真的退出——工程是每次修改都原子落盘的，没有"未保存"状态要处理。

## 四个页面

顶栏左侧的四枚分段钮就是全部导航：**首页 / 工作室 / 图片处理 / Agent 接入**。
设置、导出、模板创建、危险操作确认都是浮层（玻璃 sheet），不跳页、不叠页。

### 首页

最近工程的真实缩略图、尺寸预设 chips（海报 3:4、方图、故事 9:16、小红书、电商主图、
A4、长图…）、模板入口，以及一条本地接口状态：显示当前端口和一键复制的 MCP 配置。
接口状态是**实测**的，不是画上去的——服务没起来它会变灰。

### 工作室

```
┌ 顶栏：工程名 · 保存状态 · 画板尺寸 · 撤销/重做 · 缩放 · 导出 ┐
│ 左：画板/图层/素材/模板 │ 中：画布 │ 右：样式/布局/检查 │
└ 右下：Agent 面板（可收起成一枚药丸）┘
```

- 画布显示的是**引擎自己编译出来的 SVG**，不是界面另画的一份。所以你看到的
  就是导出会得到的，包括换行位置（浏览器和导出器拿到的是同一份字体文件）。
- 选中图层后有 8 个缩放手柄 + 旋转柄；拖动时显示对齐参考线；松手才提交一次命令。
- 双击文字直接改。`Ctrl+D` 复制、`Del` 删除、`Ctrl+Z / Ctrl+Shift+Z` 撤销重做、
  方向键微调 1px（按住 Shift 是 10px）、滚轮以光标为中心缩放、空格拖拽平移。
- 图层树可以拖拽排序与嵌套、点眼睛隐藏、点锁锁定。锁定的图层，智能体也动不了它。
- 右侧 **布局** 页显示的是语义约束（"在 标题 下方 · 间距 90"），不是像素坐标；
  点开 `为什么在这儿` 能看到求解顺序。**检查** 页列出真实问题，点一行会选中并高亮对应图层。

### 图片处理

拖进图片 → 用玻璃步骤条拼一条链（`裁切 1:1 → 缩放 0.5 → 锐化 1.2 → 水印`）→
前后对比滑杆 → 批量表格逐行显示真实结果（尺寸、体积、失败原因）→ 导出格式与质量。
这一步和工作室共用同一个引擎，只是入口不同：工作室是"排版一张图"，这里是"处理一批图"。

### Agent 接入

MCP 配置（一键复制）、HTTP 示例（一键复制）、真实工具清单（来自 `system.tools`）、
调用日志（每条含方法、耗时、成功与否、改了哪些图层）、任务进度与取消按钮。
这一页存在的意义是：**让人看见智能体正在对自己的工程做什么。**

## Agent 面板

输入中文需求，比如"用这张图做张极简电商海报，标题在上、产品居中、Logo 放左下角安全区"。
面板会依次显示：

1. **计划** —— 它准备做哪几步（chips）；
2. **工具调用** —— 每一步真实的方法名 + 参数 + 返回摘要，可展开；
3. **预览** —— 引擎渲染出来的图；
4. **结果** —— 改动了哪些图层，检查报告有没有 error。

没有配置模型密钥时，面板走**确定性模板生成**：从你的话里抽取标题/副标题/图片/配色/尺寸，
映射到内置版式和语义约束。它依然会如实列出它调用了哪些工具——不会假装是大模型创作的。

接受 / 回滚 是面板底部的两个动作；回滚就是 `history.undo`，和按 Ctrl+Z 完全等价。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `Ctrl/Cmd + N` | 新工程 |
| `Ctrl/Cmd + S` | 立即保存 |
| `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` | 撤销 / 重做 |
| `Ctrl/Cmd + D` | 复制图层 |
| `Delete` | 删除图层 |
| `Ctrl/Cmd + G` / `Ctrl/Cmd + Shift + G` | 编组 / 解组 |
| `Ctrl/Cmd + E` | 导出 |
| `Ctrl/Cmd + =` / `-` / `0` / `1` | 放大 / 缩小 / 实际大小 / 适配窗口 |
| `空格 + 拖拽` | 平移画布 |
| `方向键` / `Shift + 方向键` | 微调 1px / 10px |
| `Ctrl/Cmd + A` | 全选当前画板 |

## 工程放在哪里

默认 `%USERPROFILE%\AgentCanvas\projects\<id>\`：

```
project.json     文档（版本化 Scene Graph）
assets/          导入的原始素材（按 sha256 命名、自动去重）
thumbs/          素材缩略图缓存
exports/         导出产物
versions/        快照（project.snapshot / history.rollback 用）
preview.png      最近一次预览
```

`project.export_bundle` 会把整个目录原样复制成 `<name>.acanvas/`——一个普通文件夹，
不是私有压缩包；`project.import_bundle` 反过来读它。跨机器、跨版本都能打开，
缺素材缺字体会在检查报告里明确列出来，而不是静默替换。
